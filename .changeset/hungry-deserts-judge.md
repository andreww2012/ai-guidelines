Introduced extra sections, which are rules for specific tools that are kept in separate files and can be added to the guidelines. The `setup` command asks which ones to add, and `setupGuidelines` takes them in the new `extraSections` option. The ones for the dependencies in `package.json` are added by default. A copy of the guidelines gets them in the places marked for them, while a link to the guidelines on GitHub gets links to them next to it.

Added the Vue extra section and moved the Vue rules there from the guidelines
